# v0.1.0 검증 기록

검증 환경: Linux, Python 3.12. 실행일 2026-10-12.

- `python -m unittest discover -s tests -v`: 40개 테스트 통과.
- 정상 demo: 기대 충족 12, 위반 0, 판정보류 0, 오류 0.
- 취약 demo: 기대 충족 4, 위반 8. 여러 역할에서 발견한 중복을 대상별로 묶으면 6개 의도된 결함이다.
- benchmark 3회: 정상/취약 각 6사례 × 3회 = 36사례. TP 18, TN 18, FP 0, FN 0, 미완료 0. 이는 자체 fixture의 회귀 검증이며 일반 보안 탐지율 또는 경쟁 도구 대비 성능이 아니다.
- setuptools wheel build 성공 (런타임 의존성 없음).
- 로컬 LLM 연동: 가짜 HTTP 응답 서버로 요청 본문과 응답 처리를 테스트. 실제 모델 추론 품질은 미검증.
- 보고서: HTML escaping, JSON 직렬화, 원문·토큰·URL 제외 테스트 통과. 현재 환경에 브라우저 실행 파일이 없어 실제 브라우저 레이아웃·필터 동작의 시각 검증은 실행하지 못했다.
- 실제 회사 서비스, 실제 DB, 실제 SSO, 외부 모델: 실행하지 않음.
- Windows/macOS 및 Python 3.11/3.13: 로컬 실측하지 않음. GitHub CI에 Windows/Linux 3.11~3.13 매트릭스 포함.

## 독립 코드 리뷰와 수정

독립 리뷰에서 확인된 불완전 Content-Length 응답의 성공 오판, DNS/헤더 대기의 시간 제한, HTTP 프로토콜 오류 처리, 익명 자격을 회수 세션으로 사용하는 잘못된 실험 구성을 수정했다. 관련 회귀 테스트 포함.

추가로 인증 값 동일 여부, 설정의 잘못된 ID 형식, LLM 집계의 숫자 자료형 검증을 보완했다. 로컬 AI 연결에도 wall-clock 제한을 적용했다.

응답 크기 상한을 넘긴 요청은 보수적으로 판정보류 처리한다. 따라서 큰 응답에서 일부 표식이 보여도 fail로 집계되지 않을 수 있다. 전체 자료의 안전을 의미하지 않는다. 공개할 소스에는 회사 URL과 인증 값이 없다.
