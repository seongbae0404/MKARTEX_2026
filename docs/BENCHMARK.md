# 비교 실험 프로토콜

동봉 benchmark는 6가지 합성 결함을 정상/취약 모드로 반복하는 회귀 실험이다. 정상/취약 각 6사례 × 반복 횟수로 계산한다. 한 대상에서 역할별 fail 하나 이상이면 해당 사례 탐지로 센다. 취약 사례의 error/inconclusive는 미탐에 포함하며 정상 사례의 미완료는 true negative로 세지 않는다. unresolved도 별도 공개한다.

## PentAGI와 실제 비교

1. 세 도구에 동일한 독립 실험용 웹앱·가짜 문서·테스트 계정·예상 권한을 제공한다. 동봉 fixture는 정답 표식 기반이므로 이것만으로 일반 탐지력을 비교하지 않는다.
2. scope, 정보량, 인증 계정, 허용 도구와 행동, 시간·비용 한도를 맞춘다. 이 프로젝트에만 정답 위치를 주고 상대에게 탐색시키는 비교를 하지 않는다.
3. 공통 지원 영역인 명시적 웹 접근·권한 검증과 전체 제품 기능 비교를 분리한다. 업로드/DB 항목은 이 프로젝트에서 lab/스냅샷 범위임을 표시한다.
4. 도구 버전/commit, 모델, 프롬프트, 설정, CPU/RAM, 네트워크 조건을 고정하고 3~5회 반복한다. 매번 대상 DB와 도구 메모리를 초기화한다.
5. 사람이 보유한 정답표와 재현 로그로 판정한다. 탐지율, 정밀도, 정상 오탐률, 판정보류, 시간 초과, API 비용, peak RAM, 요청 수를 공개한다. 한 취약점의 중복 경고를 여러 발견으로 세지 않는다.
6. 로컬 LLM 모델 메모리와 점검 실행기의 메모리를 분리한다. 이 도구의 기본 실행 API 비용은 0이지만 탐지 범위도 제한적이라는 조건을 함께 적는다.
